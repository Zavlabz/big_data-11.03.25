test_get_fact_success – Проверяет корректное получение и сохранение факта из API при успешном ответе.
test_get_fact_bad_status – Проверяет обработку HTTP‑ошибок (например, 500 Internal Server Error) и преобразование их в APIError.
test_get_fact_connection_error – Тестирует обработку ошибки соединения (например, отсутствие интернета) и преобразование её в APIError.
test_get_fact_json_error – Проверяет, что при некорректном JSON от API выбрасывается ValueError.
test_get_fact_analysis_empty – Тестирует анализ пустого факта (возвращает длину 0 и пустую частотную статистику).
test_get_fact_analysis_with_fact – Проверяет корректность анализа непустого факта (длину строки и частоту символов).
test_integration_flow – Тестирует полный цикл работы: получение факта из API и его последующий анализ.
